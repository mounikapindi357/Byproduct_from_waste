# ♻️ ByProduct from Waste

A full-stack web application designed to reduce food waste and promote recycling by connecting donors with NGOs and recycling partners.

---

## 🚀 Key Features

- 👤 User registration and login
- 🍱 Food donation submission and tracking
- ♻️ Recyclable waste donation management
- 📸 Picture uploads for donations
- ⏳ Food validity and expiry tracking
- 📊 Admin dashboard with donation statistics
- 📁 CSV export of donation records

---

## 🧰 Tech Stack

### Frontend
- React.js
- Bootstrap
- Axios

### Backend
- Python
- Flask

### Database
- MySQL

---

## ⚙️ Setup Instructions

### 1. Clone Repository

```bash
git clone https://github.com/mounikapindi357/Byproduct_from_waste
cd byproduct_from_waste
```

### 2. Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### 3. Frontend Setup

Open another terminal:

```bash
cd frontend
npm install
npm start
```

---

## 🔄 How It Works

1. Users register and log in.
2. Donors submit food or recyclable waste details.
3. React sends requests to Flask APIs using Axios.
4. Flask processes requests and interacts with MySQL.
5. Users can track donation information and status updates.
